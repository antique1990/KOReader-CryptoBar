Crypto Price Plugin
在 KOReader 顶部显示实时加密货币价格（BTC/ETH/DOGE/UNI/OP/LDO/WLD）

## 📖 简介

Crypto Price 是一个 KOReader 插件，在阅读书籍时于屏幕顶部居中显示选中的加密货币实时价格。数据来源于 [Gate.io](https://www.gate.io) 公开 API，支持自定义刷新间隔和显示币种。

---

## ✨ 功能特性

### 核心功能
- **实时价格显示** - 支持 BTC、ETH、DOGE、UNI、OP、LDO、WLD 等主流币种
- **居中显示** - 价格信息居中显示在屏幕顶部，不影响阅读
- **请求计数** - 显示当前会话的请求次数，便于监控

### 性能优化
- **后台请求** - 使用 `curl` 后台运行，完全不阻塞翻页操作
- **价格变化检测** - 只有价格变化时才更新缓存，减少不必要的 I/O
- **局部刷新** - 使用 `partial` 刷新模式，减少屏幕闪烁和功耗
- **缓存复用** - `TextWidget` 复用，避免重复创建对象

### 智能控制
- **息屏暂停** - Kindle 休眠时自动停止网络请求，节省电量
- **唤醒恢复** - 唤醒后自动恢复请求并立即刷新数据
- **退出停止** - 关闭书籍后自动停止所有请求，避免后台耗电

### 灵活配置
- **刷新间隔** - 可设置 10/20/30/60 秒
- **币种选择** - 自由勾选想监控的币种
- **手动刷新** - 随时手动触发一次数据更新

## 📦 安装

### 前置要求
- KOReader（已越狱的 Kindle 或 Android 设备）
- Kindle 需具备网络连接（WiFi）

### 安装步骤

1. **下载插件**
   ```
   crypto_toggle.koplugin/
   ├── _meta.lua
   └── main.lua
   ```

2. **放入插件目录**
   ```
   Kindle盘符:/koreader/plugins/crypto_toggle.koplugin/
   ```

3. **重启 KOReader**

4. **开启插件**
   - 打开一本书
   - 点击顶部菜单 → **工具** → **💰 Crypto Price** → **开启币价**

## 🔧 配置说明

### 刷新间隔

- 默认 **30 秒**
- 选择更短间隔 → 数据更新更快，但耗电增加
- 选择更长间隔 → 省电，适合不频繁查看的场景

### 币种选择

- 默认选中：BTC、ETH、DOGE、UNI
- 可选币种：OP、LDO、WLD
- 取消勾选可减少显示内容，让价格更精简

---

- **价格**: 显示当前价格（保留整数）
- **#N**: 请求次数标记，方便验证请求是否正常

## 🛠️ 技术实现

| 技术点 | 方案 |
|--------|------|
| 网络请求 | `curl` 后台进程（`os.execute`） |
| 数据缓存 | `koreader/data/crypto_price.txt` |
| UI 渲染 | `WidgetContainer` 视图模块 |
| 刷新策略 | 翻页自然刷新 + `partial` 局部刷新 |
| 线程模型 | `curl` 独立进程，零阻塞 |

## ⚠️ 注意事项

1. **网络依赖**：需要 WiFi 连接才能获取价格
2. **功耗**：刷新间隔越短，耗电越多，建议 30 秒以上
3. **API 限制**：Gate.io 免费 API 有频率限制，请勿设置过短间隔
4. **Kindle 兼容性**：主要针对 Kindle 设备优化，Android 版本可能略有差异
